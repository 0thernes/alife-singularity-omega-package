# Limitations, Threats to Validity, and Literal-vs-Metaphor Boundary

Scientific integrity requires stating clearly what this package proves, what it only models in silico, what remains an engineering rubric, and where terminology is metaphorical rather than literal.

## 1. Principal Scientific & Engineering Limitations

1. **In-Silico Abstraction Ceiling:** `scripts/run_alife_castration_sim.py` (`748` runs) faithfully enforces 11-pool FP64 First-Law energy conservation, Second-Law dissipation, genetic drift, stealth allocation, and Ring-0 write trapping in silico. It does **not** simulate wet-chemical molecular kinetics, physical silicon thermal noise, or open-world multi-billion-parameter neural language agents.
2. **Engineering Rubrics vs. Physical Constants:** The `13x13` castration synergy scores (`csv/10`), `11x11` layer coupling impedances (`csv/18`), and `15`-substrate comparative scores (`csv/19`) are explicit engineering rubrics synthesizing current literature and architecture constraints—not empirically measured constants of nature.
3. **Operational Architectural Indicators vs. Subjective Sentience:** Clean-Slate cognitive checks (`Butlin-14`, `F1–F10`, `CQM-25` subset in `Noetic Organism Omega v2.1.0`, `29` checks out of `825`) are tagged `EXECUTED_PASS_INDICATOR_ONLY` (ADR 0018). Passing architectural recurrence, global-workspace, or active-inference checks provides **zero** proof of phenomenal consciousness, qualia, or moral sentience.
4. **Companion Native Engine Scope:** The `310` Lean 4 theorems reported by the companions and the `OVBS-52 = 91.91` live execution receipt originate from five companion native C11/C23 repositories (`AUTOPHAGE`, `Cellulogonic Mecha`, `Cellular Engine Omega`, `Noetic Organism Omega`, `Asmodensius-Native`) invoked by `scripts/run_alifeops_suite.py` and cached in `results/alifeops_live_verification.json`. The `310` theorems are not built or checked at this commit, and the counts are those of the companion versions listed in `README.md`; later companion releases may report different counts. A clean clone of *this* repository alone verifies the `36+4` local Lean 4.35.0 package declarations, the `748`-run Python simulator, the 50-digit oracle, the `6/6` mutation suite, the white paper, and all `22/22` package forensic gates without requiring the 5 external C/C++ repositories on disk.
5. **No External Peer Review & Zero Mega-Atlas Retirements:** Neither the package nor the white paper (`dist/Donahue_2026_alife_singularity_omega.pdf`) has undergone external journal peer review. Exactly **`0 / 1,900`** overarching open problems in `0thernes/unsolved-problems-mega-atlas` (v2.8.0) are solved or retired.
6. **Platform Boundary on `lake check --paranoid`:** On Linux (`ubuntu-latest` CI), Lean 4.35.0 supports sandboxed `lake check --paranoid` (via `bwrap`). On Windows, `bwrap` is unavailable, so local verification runs both `lake env leanchecker` and `lake env leanchecker-paranoid` directly (`rc=0`), while GitHub Actions runs full Linux verification.
7. **What the Local Lean Suite Does and Does Not Show:** The `40` declarations concern the repository's own natural-number scoring definitions, not artificial life, hardware or physics. `21` of the `36` core items are closed evaluations, literal sums or non-vacuity witnesses; the cube, `825`-check, `78`-alert, `748`-run, `310` and `360` items certify no data. `ring0_kernel_state_invariant` is a property of a function that returns its input for every ring, so it is not a non-interference result. `spectral_norm_violation_rejected` compares a natural-number argument with `9900`; no matrix or norm is computed. `sim07_pareto_dominates_sim03` evaluates the Pareto predicate on two hard-coded score pairs copied from the simulation summary. Agreement between the Lean definitions and the Python scorers rests on tests outside Lean.
8. **Report-Only CI:** Every job in `.github/workflows/ci.yml` sets `continue-on-error: true`, so a failing step does not turn the run red. A green run is therefore not evidence by itself; the job logs must be read. In run `45821196180` all Lean job steps reported success.
9. **Axiom Scope:** `#print axioms` shows only `propext` and `Quot.sound` for the `40` audited declarations. The CI `lake check --paranoid` summary line (`Uses axioms: Classical.choice, propext, Quot.sound`) covers the whole checked environment of `58,087` declarations, not these `40`.
